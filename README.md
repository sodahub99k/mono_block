# Mono Block

Scratch によく似た、ブロックをつないでゲームをつくるビジュアルプログラミング IDE。

デモ: [https://sodahub99k.github.io/mono_block/](https://sodahub99k.github.io/mono_block/)

## できること

- 旗・クリック・キーのイベントからスクリプトを起動
- 動き・見た目・音・制御・調べる・演算・変数のブロック
- ステージ上でスプライトを動かしてミニゲームを作る
- サンプル（バウンス / キーボード操作 / スター集め）
- プロジェクトの自動保存（ブラウザ内）と JSON の書き出し・読み込み

## 開発

```bash
pnpm install
pnpm dev
```

## 公開

`main` へ push すると GitHub Actions が GitHub Pages にデプロイします。
